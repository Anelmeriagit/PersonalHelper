## Переменные окружения Vercel (только имена, значения не хранить в репозитории)
| Имя | Назначение |
|---|---|
| `KV_REST_API_URL`, `KV_REST_API_TOKEN` | Upstash Redis (запасные имена `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN`; код читает сначала `KV_*`) |
| `DB_PREFIX` | префикс ключей Redis (`t:` в тестовом проекте, в бою не задавать) |
| `MAX_USERS` | максимум аккаунтов (по умолчанию 500) |
| `BACKUP_KEY` | ключ шифрования резервных копий: 64 шестнадцатеричных символа, генерируется как `CRON_SECRET`; нужен с 4.3, хранить в менеджере паролей |
| `AUTH_USER` | **больше не читается** (с 3b бот берёт документ привязанного аккаунта); удалить из Vercel после подтверждения владельца |
| `SESSION_SECRET` | ключ подписи сессий (≥32 символов), единственный ключ подписи |
| `SESSION_VERSION` | номер сессий (по умолчанию `1`); смените, чтобы разлогинить все устройства |
| `BLOB_READ_WRITE_TOKEN` | выдаёт Vercel при подключении Blob; читает `@vercel/blob` для резервных копий (`_backup.js`, этап 4) |
| `TELEGRAM_BOT_TOKEN` | токен бота (запасное имя `BOT_TOKEN` читается, только если первой нет) |
| `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` | вход через Google (этап 5, часть 3, готово в коде; `notes/account.md`). Не заданы: кнопка ведёт назад с сообщением «Вход через Google пока не настроен» |
| `CRON_SECRET` | секрет для `/api/cron` и `/api/tg-setup`, только заголовком `Authorization: Bearer` |
| `WIFI_SSID`, `WIFI_PASSWORD`, `WIFI_SECURITY`, `WIFI_HIDDEN` | **больше не читаются** (с этапа 2 сеть вводится на сайте); удалить из настроек Vercel, если заданы |
