# Агент

Читать при правках страницы «Агент», уведомлений браузера, `sw.js`. Общие ограничения и карта файлов — `PROJECT_NOTES.md`.

## Данные (Redis `agent:<id аккаунта>`, hash `d`/`v`)
- Формат `{rows: [{id, app, h: 0..23|null, m: 0|10|…|50|null, at}]}`. `app` — встроенный id (`app`, `opera`, `mozilla`, `edge`) или своё название (до 40 символов, без `< > " ' ` & \`, пробелы схлопываются; «Opera» в любом регистре становится встроенным id; `constructor` и `__proto__` — обычные названия). Отдельного списка своих названий нет, они берутся из строк. До первого сохранения отдаются четыре строки по умолчанию без времени. Лимит 12 строк, приложения можно повторять.
- Запись списка целиком через `readRec`/`writeRec` (`api/_lib.js`), при гонке до 4 перечитываний, затем `409 busy`. Проверка — `cleanRows`, `cleanApp` в `api/agent.js`.
- `at` — момент сброса в мс (UTC) у строки с часами и минутами; время одноразовое. `withAt` при сохранении ставит ближайшее ч:мин по часам пояса аккаунта (`nextAt(h, m, now, tz)` в `api/_tz.js`; нет поля `tz` = Москва; наступившее время — завтра). Пока ч:мин строки не менялись, `at` не двигается (перестановка, смена названия). «Сбросить» или смена ч:мин дают `at:null` или новое значение; `at` от клиента сервер игнорирует; старые строки без `at` получают его при первом открытии страницы.
- Смена пояса (`set-tz`): `at` остаётся, ч:мин пересчитываются из него (`retimeRows`, `retimeAgent`; на сетке 10 минут округление вниз у смещений вроде +05:45; `notes/reminders.md`, «Часовые пояса»).

## API
`GET /api/agent` → `{rows}` (без сессии `401 {error:'auth'}`). `PUT /api/agent` с `{rows}` заменяет список (перед записью читает прежний ради `at`), ответ тот же `{rows}`; пояс (+1 команда `GET acc:<id>`) читается, только когда `at` надо считать заново. Ошибки: `400 bad request|limit`, `409 busy`, `500 server`. `Cache-Control: no-store`.

## Фронтенд (`js/agent/`)
- `state.js` (состояние `A`, `AG_APPS`, `AG_MAX`, `AG_GRACE` = 30 мин, `AG_SAVE_MS` = 1800 мс, `agNextAt`, `agDay`), `index.js` (`agLoad`, `agRender`, `agSchedule`, `agFlush`, `agLeave`), `notify.js` (`agMarks`, `agCheck`, `agToggleNotify`, `agFetchN`), `drag.js` (pointer events за значок слева `button[data-ag=grip]`; с клавиатуры стрелки на значке).
- Автосохранение через 1800 мс; при уходе со вкладки или закрытии `agLeave` сразу сохраняет ждущую правку с `keepalive` (если запись идёт, следующую отправку делает цепочка в `agFlush`). Возврат на вкладку перечитывает строки не чаще `REFRESH_MS` (5 минут, `fresh('ag')`), переход на страницу — всегда. 401 → `authFail()`.
- Селекты часов (00–23) и минут (00–50, шаг 10). Последний пункт списка приложений «＋ Свой вариант…» открывает `dlgPrompt`; при отмене строка возвращается к прежнему значению.
- Под строкой со временем подпись («Ближайший · через 2 ч 10 мин», «завтра · через …», «Сброс прошёл», «Укажите минуты/часы») и кнопка «Сбросить» (обнуляет `h`, `m`, `at`). `agMarks()` ставит `.next` на ближайший будущий сброс и `.past` на прошедшие (при рендере, правке и каждые 30 с). При смене ч:мин клиент сразу считает предварительный `at`, после сохранения подставляет серверный. Время считается по поясу режима (`js/time.js`, пара `js/tz.js`).
- Уведомления: кнопка «Включить уведомления» (разрешение → `agNotify` в localStorage → регистрация `sw.js` → тестовое уведомление). Текст «Время сброса — 10:00», с городом в скобках, если пояс режима не совпадает с поясом устройства. `agCheck()` показывает уведомление, когда `at` наступил (`setTimeout` на ближайший `at`, проверка раз в 30 с и при возврате на вкладку); сброс старше `AG_GRACE` не показывается; показанные лежат в localStorage `agFired` (`{id: at}`), `tag` убирает дубли между вкладками. Вне страницы «Агент» строки берёт `agFetchN` (не чаще `REFRESH_MS`, только при включённых уведомлениях).
- **Ограничение:** уведомление приходит, только пока сайт открыт (вкладка или установленное приложение); на iPhone нужно приложение на экране «Домой». `sw.js` ничего не кеширует, только показывает уведомления и по клику фокусирует окно или открывает `/#agent`. В Telegram по времени сброса ничего не шлётся (Hobby).

## Гость
Список в localStorage (`g-ag`, формат `{rows}`); `js/local.js` отвечает на `GET`/`PUT /api/agent` теми же формами и проверкой (`cleanApp`, `cleanRows`, `withAt`, `nextAt`, лимит 12, коды `400`; при сбое записи `500 {error:'storage'}`). Парное правило: `api/agent.js` и `js/local.js` менять только вместе (`tests/guest-mirror.test.mjs`). Уведомления гостя те же, строки из localStorage. Слияние и переход в гостя — `notes/guest.md`.
