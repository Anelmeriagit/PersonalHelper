# Агент

Читать при правках страницы «Агент», уведомлений браузера, `sw.js`. Общие ограничения и карта файлов — в `PROJECT_NOTES.md`.

## Данные (Redis, ключ `agent:<id аккаунта>`, с префиксом `DB_PREFIX`)
- Формат: `{ rows: [{id, app, h:0..23|null, m:0|10|..|50|null}] }`. `app` — id встроенного приложения (`app`, `opera`, `mozilla`, `edge`) или своё название, введённое вручную (до 40 символов, без `< > " ' ` & \\`; пробелы схлопываются; ввод «Opera» в любом регистре превращается во встроенный id). Отдельного списка своих названий нет: они берутся из строк и появляются в выпадающих списках всех строк, пока хотя бы одна строка их использует. Порядок массива = порядок на странице. До первого сохранения отдаются четыре строки по умолчанию без времени. Лимит 12 строк, приложения можно повторять. Список у каждого пользователя свой (с этапа 2); Blob агентом больше не используется, общий файл `agent/rows.json` остаётся в Blob неиспользуемым (удалить вручную по желанию). Запись целиком, последняя запись побеждает; чтение и запись идут через `readRec/writeRec` из `api/_lib.js` с проверкой версии Redis: при гонке до 4 перечитываний, затем `409 {error:'busy'}`. Серверная проверка: `cleanRows` в `api/agent.js`.
- Поле `at` — момент сброса в мс (UTC) у строки, где заданы и часы, и минуты. Время одноразовое: при сохранении `withAt` ставит ближайшее такое ч:мин по Москве (`nextAt`; Москва UTC+3 без перехода на летнее время; если это время уже наступило, то завтра). Пока ч:мин у строки не менялись, `at` не двигается (перестановка, смена названия): прошедший сброс остаётся прошедшим и не переезжает на завтра. «Сбросить» или смена ч:мин даёт `at:null` или новое значение. `at` от клиента сервер игнорирует. Старые строки без `at` получают его при первом открытии страницы «Агент» (клиент считает и сохраняет).

## API
- `GET /api/agent` → `{rows}` (у строк со временем есть `at`; без сессии `401 {error:'auth'}`). `PUT /api/agent` с `{rows:[...]}` — заменяет список (до записи читает прежний список, чтобы сохранить `at`), ответ тот же `{rows}` (очищенный, с `at`). Ошибки: `400 bad request|limit`, `409 busy`, `500 server`. Строки с недопустимым названием отбрасываются (`cleanApp`). `Cache-Control: no-store`.

## Фронтенд
- Модули: `js/agent/state.js` (состояние `A`, `AG_APPS`, время), `js/agent/index.js` (строки, загрузка, автосохранение), `js/agent/notify.js` (подсветка, `agCheck`, уведомления), `js/agent/drag.js` (перетаскивание).
- Страница «Агент» (`#agent`, модули `js/agent/`): `agLoad`, `agRender`, `agSchedule` (автосохранение через 400 мс), `agFlush`, `agLeave` (сохранение с `keepalive` при уходе). Перетаскивание на pointer events за значок слева (`button[data-ag=grip]`, `touch-action:none`): `agDragMove` переставляет строку в DOM и сдвигает её `transform`, `agDragEnd` синхронизирует порядок с `ag.rows`. С клавиатуры: стрелки вверх/вниз на значке. Селекты часов (00–23) и минут (00–50 шаг 10) с плейсхолдерами «ч» и «мин». Последний пункт списка приложений «＋ Свой вариант…» открывает диалог `dlgPrompt` (`agNewName`); при отмене или ошибке строка возвращается к прежнему значению. При ответе сервера 401 вызывается `showLogin`. Элементы: `#agentStage`, `#agBody`, `#agMsg`, ссылка `#navAgent`; стили `.agl`, `.agr`, `.agh`, `.aga`, `.agt` в конце `style.css`. В навигации включён `flex-wrap`: на 360 px «Агент» переходит на вторую строку.
- Сброс и уведомления (`js/agent/notify.js`). Под каждой строкой со временем вторая строка `.agm`: подпись `.ags` («Ближайший · через 2 ч 10 мин», «завтра · через …», «Сброс прошёл», «Укажите минуты/часы») и кнопка `.agz` «Сбросить». `agMarks()` ставит класс `.next` на строку с ближайшим будущим `at` и `.past` на прошедшие; вызывается из `agRender`, при смене часов и минут и каждые 30 с. При смене ч:мин клиент сразу считает предварительный `at` (`agNextAt`), после сохранения подставляет серверный (`agMerge`). «Сбросить» обнуляет `h`, `m`, `at` и ставит фокус на часы. Блок `.agn` над списком: кнопка «Включить уведомления» (`agToggleNotify`: запрос разрешения → настройка `agNotify` в localStorage → регистрация `sw.js` → тестовое уведомление). Показ: `agShow` через `registration.showNotification` (работает и на Android), запасной вариант `new Notification`. `agCheck()` показывает уведомление, когда `at` наступил (точный `setTimeout` на ближайший `at` плюс проверка раз в 30 с и при возврате на вкладку); сброс старше 30 минут (`AG_GRACE`) не показывается; показанные запоминаются в localStorage `agFired` (`{id: at}`), поэтому после перезагрузки повторов нет, а `tag` у уведомления убирает дубли между вкладками. Строки для уведомлений вне страницы «Агент» берёт `agFetchN` (при открытии любой страницы и возврате на вкладку, не чаще раза в минуту, только если уведомления включены).
- **Ограничение:** уведомление приходит, только пока сайт открыт (вкладка или установленное приложение); на iPhone нужно приложение, добавленное на экран «Домой». `sw.js` ничего не кеширует, только показывает уведомления и по клику фокусирует окно (или открывает `/#agent`). В Telegram по времени сброса ничего не шлётся (тариф Hobby, см. `PROJECT_NOTES.md`).
