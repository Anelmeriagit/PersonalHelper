# Redis: ключи, запись и расход команд (читать, когда правка добавляет запросы к API или команды Redis)

Хранилище: Upstash Redis через REST (`api/_db.js`, без пакетов; запись по версии через Lua, CAS). Все ключи с префиксом `DB_PREFIX` (на боевом сайте `t:`).

## Ключи
- `acc:<id>`, `gid:<sub>`, ключи привязки Telegram (`tg:`, `tgp:`, `tgs`, `tgu:`) и лимиты `rl:` — `notes/session.md`.
- `pair:<id>` — связь двух аккаунтов; `shr:<меньший id>:<больший id>` — общие напоминания пары; `wfs:<меньший id>:<больший id>` — общий список Wi-Fi пары.
- `doc:<id>` — кэшбэк; `agent:<id>` — агент; `wifi:<id>` — сети Wi-Fi; `rem:<id>` — личные напоминания; `bot:<id>` — состояние бота.
- `dueq` — индекс cron «кому пора слать» (отсортированное множество, `notes/reminders.md`, «Индекс dueq»).
- Временные: `cron:hb` (пульс основного cron), `cron:lock` (замок), `cron:bk` (отметка проверки копии), `rl`, `tgt`, `tgp`.
- Резервная копия читает известные виды ключей по типу (`KNOWN`), временные (`TEMP`) не копирует; новый вид ключа добавлять в `KNOWN` или `TEMP` в `api/_backup.js` (`notes/backup.md`).
- Старые файлы Blob `bot/state.json` и `agent/rows.json` (если остались) не используются, удалить вручную по желанию.

## Расход команд (Upstash Free: 500 тыс. в месяц; каждая команда в pipeline и в транзакции считается отдельно)
- Сайт обновляет раздел при возврате на вкладку не чаще раза в `REFRESH_MS` (5 минут, константа в `js/api.js`, метки `fresh(раздел)`/`stamp(раздел)` в `S.at`). Сразу, без паузы: при входе, переходе на «Напоминания», Wi-Fi и «Агент», смене месяца, после конфликта сохранения и в опросе привязки Telegram. «Кэшбэк» при переходе из другого раздела тоже обновляется не чаще `REFRESH_MS` (решение владельца, проверено на двух устройствах).
- Автосохранение кэшбэка и агента через 1800 мс.
- Новые запросы на клиенте и новые команды на сервере добавлять с оглядкой на расход; число команд эндпоинта проверять в тесте через `__cmdLog` заглушки (`tests/redis.mjs`).
- `GET /api/reminders`: без связи 3 команды, со связью 6 (с общей записью). Любая запись напоминаний — ещё одна команда (`ZADD dueq`).
- `GET /api/data`: без связи 3, со связью 6; кэшбэк партнёра приходит в том же ответе и обновляется в те же `REFRESH_MS`.
- `GET /api/wifi`: без связи 2, со связью 4.
- cron читает только тех, кому пора, из `dueq`: запуск без задач — 6 команд независимо от числа пользователей.
- Резервная копия: одна команда на ключ, новая копия раз в 7 суток.
- Лимиты тарифов Upstash/QStash и расчёт для расписания — `notes/reminders.md`, «Лимиты Upstash».
